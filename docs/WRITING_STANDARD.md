# Стандарт текстов / Writing standard

## RU

Публичная документация SSC14 двуязычна: сначала RU, затем EN. Обе версии должны содержать одинаковые технические условия, ограничения, версии и результаты проверки. Для больших руководств допустимы отдельные `docs/ru/*` и `docs/en/*`; небольшие документы, PR и ADR используют два раздела в одном файле.

Используйте один согласованный термин для одного понятия и проверяйте его по [словарю](TERMINOLOGY.md). Пишите короткими ясными предложениями. Приводите точные команды, предусловия и ожидаемый результат. Указывайте только те тесты, которые реально запускались. Не маскируйте предположения под факты.

ASD-STE100 используется как источник общих принципов ясности, **не** как заявление о соответствии стандарту и **не** как обязательный словарь для русского текста.

## EN

SSC14 public documentation is bilingual: RU first, then EN. Both versions must carry the same technical conditions, constraints, versions, and verification results. Long guides may use separate `docs/ru/*` and `docs/en/*` files; short documents, PRs, and ADRs use two sections in one file.

Use one agreed term for each concept and verify it against the [glossary](TERMINOLOGY.md). Write short, clear sentences. Provide exact commands, prerequisites, and expected results. State only tests that actually ran. Do not present assumptions as facts.

ASD-STE100 is a source of general clarity principles, **not** a compliance claim and **not** a mandatory vocabulary for Russian text.
