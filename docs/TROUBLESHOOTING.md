# Устранение проблем

## Не подходит версия Java

Сравните `java -version` и вывод `gradlew --version`: проект рассчитан на JDK 25. Переменная `JAVA_HOME` должна указывать на корень JDK, содержащий `bin`, а не на сам каталог `bin`.

Если Gradle продолжает использовать старую JVM, остановите daemon командой `gradlew --stop` и повторите запуск после изменения окружения. В Windows используйте `.\gradlew.bat`, в Linux/macOS — `sh ./gradlew`.

## Не загружаются зависимости

При первой сборке скачиваются Gradle, Minecraft, NeoForge и зависимости мода. Найдите в журнале URL и причину ошибки: тайм-аут, недоступность репозитория и отсутствие версии требуют разных решений. Проверьте подключение и настройки proxy, затем повторите команду. Не заменяйте зависимость случайным JAR другой версии Minecraft.

## JVM сообщает о нехватке памяти

При подготовке Minecraft запускаются дополнительные Java-процессы. Сообщение `insufficient memory` или Windows error 1455 указывает на нехватку доступной памяти либо лимита выделения памяти ОС. Закройте тяжёлые приложения, проверьте доступную память и параметры файла подкачки. Увеличение только `org.gradle.jvmargs` не гарантирует решения для дочернего процесса декомпилятора.

## Test Worker не находит скомпилированный класс

Если Gradle сообщает `ClassNotFoundException`, проверьте имя класса, каталог исходников и результаты компиляции. На Windows дополнительно попробуйте checkout в коротком пути латиницей: в путях с кириллицей возможны проблемы передачи classpath через JVM argument files. Для диагностики выполните `domainTest --stacktrace --info` и сохраните журнал.

## Игра не загружает мод

Проверьте совпадение версий Minecraft, NeoForge и Java с [README](../README.md), а также наличие Curios, ItemPhysic, CreativeCore и Fusion. Для диагностики нужны `logs/latest.log` и, если создан, файл из `crash-reports`. Сообщение загрузчика об отсутствующей зависимости обычно указывает её mod ID и допустимый диапазон версий.

## Что приложить к сообщению об ошибке

- Версии мода, Minecraft, NeoForge, Java и операционной системы.
- Ссылку на релиз или SHA коммита для самостоятельной сборки.
- Шаги воспроизведения, ожидаемый и фактический результат.
- Список остальных модов, журнал или crash report.
- Для ошибки CI — ссылку на запуск и название упавшего задания.

Перед публикацией журналов удалите токены, приватные адреса и другие личные данные. Тестовый мир прикладывайте только если он необходим для воспроизведения и может быть опубликован.
