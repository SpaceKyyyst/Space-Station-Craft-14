# Терминология / Terminology

Используйте согласованные термины в публичных текстах. Recommended identifier указывает на текущий код и не требует создания новой абстракции. / Use the agreed terms in public writing. A recommended identifier points to current code and does not require a new abstraction.

| газовая смесь | gas mixture | `GasMixture` |

| давление | pressure | `pressure` |
| энергосеть | power network | `EnergyNetwork` |
| подсистема доступа | access subsystem | `PlayerAccessService` |

| сетевой payload | network payload | `CustomPacketPayload` |
| идентификатор реестра | registry ID | `Identifier` |
