# Шлюзы

## Доступ

Шлюз проверяет ID-карты в текущем инвентаре игрока, включая контейнеры
и слоты Curios. Достаточно одного доступа из списка, настроенного у шлюза.
Если список пуст или включён аварийный доступ, карта не требуется.
Удаление карты и изменение её прав действуют при следующем взаимодействии
со шлюзом, без ожидания обновления данных игрока.

## Провода

Панель открывается отвёрткой. Для разрезания или восстановления провода
нужны кусачки в любой руке. Меню управляет только тем шлюзом, для которого
было открыто, и закрывается при закрытии панели или удалении от шлюза.
Назначения восьми проводов сохраняются у конкретной двери; цвет не задаёт
универсального назначения для всех шлюзов.

## Укрепление

Все действия ниже выполняются с зажатым Shift по закрытому шлюзу
с закрытой панелью. Инструмент или материал должен находиться в основной руке.

1. Применить стопку минимум из двух стальных листов: два листа будут закреплены.
2. Применить активную сварку: листы станут укреплением, расход топлива — 100 единиц.
3. Для снятия применить активную сварку повторно, затем лом.
   Лом возвращает два листа и не снимает заваренное укрепление.

Для сварочного действия необходимо минимум 250 единиц топлива:
100 на действие и 150 остатка, соответствующего порогу отключения сварки.
Укрепление замедляет обычное разрушение блока в три раза.
При установленных листах открыть панель отвёрткой и пользоваться проводами нельзя.

Эти действия не заменяют обычное заваривание двери без Shift.
Визуальное отображение укрепления, разборка самой двери и конструкция
высотой три блока с общей ячейкой для плитки пока находятся в разработке.
