# Space Station Craft 14

Мод для Minecraft, переносящий механики [Space Station 14](https://github.com/space-wizards/space-station-14): атмосферу и газовые реакции, энергоснабжение, оборудование и взаимодействие с объектами станции.

[Скачать релиз](https://github.com/SpaceKyyyst/Space-Station-Craft-14/releases) · [Сообщить об ошибке](https://github.com/SpaceKyyyst/Space-Station-Craft-14/issues) · [Discord](https://discord.gg/dCtBN6EBAv)

Проект находится в разработке. Наличие механики в исходниках не означает полного соответствия оригинальной игре; автоматические сборки требуют проверки игровых сценариев.

## Совместимость

| Компонент | Версия сборки |
| --- | --- |
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.71 |
| Java | 25 |
| Мод | 0.1.27 |

Версии определены в [build.gradle](build.gradle) и [метаданных мода](src/main/resources/META-INF/neoforge.mods.toml).

## Установка

1. Подготовьте профиль Minecraft 26.1.2 с NeoForge 26.1.2.71 и Java 25.
2. Скачайте `ssc_14-<версия>.jar` со страницы релиза и поместите его в папку `mods` выбранного профиля.
3. Установите зависимости для той же версии Minecraft и NeoForge:

   | Зависимость | Версия, используемая при сборке |
   | --- | --- |
   | Curios | `15.0.0-beta.2+26.1.2` |
   | ItemPhysic | `1.8.15` |
   | CreativeCore | `2.14.16-neoforge` |
   | Fusion | `1.3.15-neoforge-mc26.1` |

4. Запустите игру. При ошибке загрузки проверьте версии зависимостей и журнал `logs/latest.log`.

Зависимости объявлены в [build.gradle](build.gradle) и [Dependency.gradle](Dependency.gradle); они не включаются в JAR мода. Для существующих миров рекомендуется резервная копия перед обновлением.

Если релиз содержит `SHA256SUMS.txt`, целостность JAR можно проверить командой `Get-FileHash <файл.jar> -Algorithm SHA256` в PowerShell либо `sha256sum -c SHA256SUMS.txt` в Linux.

## Что находится в проекте

- **Атмосфера:** газовые ячейки, давление, диффузия и химические реакции.
- **Энергетика:** кабельные сети, источники и потребители энергии.
- **Оборудование:** блоки, предметы, сущности, интерфейсы и сигнальные соединения.
- **Экипировка:** интеграция с Curios и сопротивления типам урона.

Устройство подсистем и их ограничения описаны в [архитектуре](docs/ARCHITECTURE.md).

## Быстрый старт для разработки

Установите JDK 25. Gradle устанавливать отдельно не требуется: Wrapper находится в репозитории. Первый запуск требует подключения к интернету для загрузки инструментов и зависимостей.

```powershell
# Windows, из корня репозитория
$env:JAVA_HOME = 'C:\путь\к\jdk-25'
.\gradlew.bat build
.\gradlew.bat runClient
```

```sh
# Linux/macOS, JAVA_HOME должен указывать на JDK 25
sh ./gradlew build
sh ./gradlew runClient
```

Результат сборки: `build/libs/ssc_14-<версия>.jar`.

## Автоматические сборки

CI проверяет сборку и тесты для готовых к проверке pull request в `main` и push в `main`. Рабочие ветки без PR и черновые PR не запускают сборку. После успешной сборки `main` публикуется релиз с JAR и контрольной суммой. Релиз привязан к конкретному коммиту; автоматическая публикация не означает завершённое игровое тестирование.
